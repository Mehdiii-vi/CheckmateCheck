# CheckmateCheck ♟️

سیستم و الگوریتم مستقل برای ارزیابی وضعیت صفحه شطرنج و تشخیص خودکار **کیش و مات (Checkmate)**، **پات (Stalemate)**، **کیش (Check)**، **وضعیت عادی (Normal)** و **صفحه نامعتبر (Invalid)**.

این پروژه بدون استفاده از هیچ‌گونه کتابخانه آماده‌ی شطرنج (مانند `python-chess`) و به صورت کاملاً مستقل و آموزشی از صفر در پایتون پیاده‌سازی شده است.

---

## ✨ ویژگی‌های سیستم

1. **موتور ارزیابی خالص پایتون (`engine/`):**
   - تمامی محاسبات کیش، پات، کیش‌ومات و اعتبارسنجی وضعیت صفحه منحصراً توسط موتور پایتون انجام می‌شود.
2. **انتخاب نوبت در بالای صفحه:**
   - کلیدهای انتخاب نوبت (نوبت سفید ⚪ / نوبت سیاه ⚫) در بالای صفحه شطرنج قرار دارند تا تغییر نوبت بسیار سریع و در دسترس باشد.
3. **نمایش حرکات مجاز با کلیک روی هر مهره:**
   - با کلیک روی هر مهره در صفحه (چه مهره سفید باشد و چه سیاه)، خانه‌های مجاز حرکت آن به صورت دایره‌های سبز رنگ روی صفحه هایلایت می‌شوند.
4. **کارت نتیجه متمرکز و شفاف:**
   - نمایش مستقیم وضعیت ارزیابی الگوریتم (کیش و مات، پات، کیش، عادی یا نامعتبر) با برچسب‌های رنگی و پیام کوتاه.
5. **پالت مهره‌ها و ابزارها:**
   - امکان چیدن آزادانه مهره‌ها با کلیک یا درگ و دراپ (Drag & Drop)، ابزار پاک‌کن، چرخش صفحه و بازنشانی به چینش اولیه.

## 🎯 منطق الگوریتم ارزیابی

```
[چینش صفحه + نوبت حرکت]
        │
        ▼
۱. اعتبارسنجی فیزیکی صفحه (وجود دقیقاً ۱ شاه برای هر طرف، عدم همجواری شاه‌ها، نبود پیاده در ردیف ۱ و ۸، و کیش نبودن شاه حریف)
        │
        ├── در صورت خطا ──> بازگرداندن وضعیت INVALID با ذکر دلیل
        ▼
۲. موقعیت‌یابی شاه بازیکن صاحب نوبت
        │
        ▼
۳. بررسی کیش بودن شاه (is_in_check):
   - بررسی پرتوهای خطوط افقی و عمودی (رخ و وزیر)
   - بررسی پرتوهای مورب (فیل و وزیر)
   - بررسی جهش‌های L اسب
   - بررسی ضربدری پیاده‌ها
        │
        ▼
۴. محاسبه تمام حرکات قانونی (Legal Moves) برای هر دو طرف:
   - تولید حرکات شبه‌قانونی بر اساس قواعد حرکت هر مهره
   - شبیه‌سازی فرضی هر حرکت روی صفحه
   - فیلتر کردن تنها حرکاتی که پس از آنها شاه خودی در کیش باقی نمی‌ماند
        │
        ▼
۵. تصمیم‌گیری نهایی وضعیت:
   ├── تعداد حرکات قانونی = ۰ و شاه در کیش است ───────> کیش و مات (CHECKMATE) ❌
   ├── تعداد حرکات قانونی = ۰ و شاه در کیش نیست ──────> پات / مساوی (STALEMATE) ⚖️
   ├── تعداد حرکات قانونی > ۰ و شاه در کیش است ───────> کیش (CHECK) ⚠️
   └── تعداد حرکات قانونی > ۰ و شاه در کیش نیست ──────> وضعیت عادی (NORMAL) ✅
```

## 📁 ساختار پروژه

```
CheckmateCheck/
├── engine/
│   ├── __init__.py
│   ├── board.py            # ماتریس ۸×۸، پارس FEN، پیدا کردن شاه‌ها
│   ├── move_gen.py         # تولید حرکات، بررسی کیش، فیلتر حرکات قانونی
│   └── evaluator.py        # ارزیابی نهایی و نقشه حرکات هر دو طرف (moves_by_square)
├── tests/
│   ├── __init__.py
│   └── test_evaluator.py   # ۱۲ تست خودکار برای تمام سناریوهای مات، پات، کیش و حرکات
├── static/
│   ├── index.html          # صفحه وب تعاملی، نوار ابزار بالا، بورد و پالت مهره‌ها
│   ├── style.css           # طراحی مدرن دارک و نشانگرهای حرکات مجاز
│   └── app.js              # فرانت‌اند متصل به API سرور پایتون
├── server.py               # سرور سبک وب استاندارد پایتون (POST /api/evaluate)
└── README.md
```
