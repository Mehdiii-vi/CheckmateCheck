# CheckmateCheck ♟️

سیستم و الگوریتم مستقل برای ارزیابی وضعیت صفحه شطرنج و تشخیص خودکار **کیش و مات (Checkmate)**، **پات (Stalemate)**، **کیش (Check)**، **وضعیت عادی (Normal)** و **صفحه نامعتبر (Invalid)**.

این پروژه بدون استفاده از هیچ‌گونه پکیج یا جعبه‌سیاه آماده‌ی شطرنج (مانند `python-chess`) و به صورت کاملاً مستقل و آموزشی از صفر پیاده‌سازی شده است تا منطق و گام‌های الگوریتم ارزیابی وضعیت کاملاً شفاف، قابل درک و توسعه‌پذیر باشد.

---

## 🎯 منطق و عملکرد الگوریتم

ارزیابی هر وضعیت در ۵ مرحله اصلی انجام می‌شود:

```
[چینش صفحه + نوبت حرکت]
        │
        ▼
۱. اعتبارسنجی فیزیکی صفحه (آیا دقیقاً یک شاه سفید و یک شاه سیاه هست؟ آیا شاه حریف در کیش نیست؟)
        │
        ├── نامعتبر ──> بازگرداندن وضعیت INVALID با ذکر دلیل
        ▼
۲. موقعیت‌یابی شاه بازیکن صاحب نوبت
        │
        ▼
۳. بررسی کیش بودن شاه (is_in_check):
   - بررسی خطوط مستقیم افقی و عمودی (رخ و وزیر)
   - بررسی قطرهای مورب (فیل و وزیر)
   - بررسی خانه‌های L-شکل (اسب)
   - بررسی تهدیدات ضربدری یک‌خانه‌ای (پیاده)
        │
        ▼
۴. محاسبه تمام حرکات قانونی (Legal Moves):
   - تولید حرکات شبه‌قانونی (Pseudo-Legal) بر اساس قوانین حرکت هر مهره
   - شبیه‌سازی فرضی هر حرکت روی صفحه
   - بررسی اینکه آیا پس از حرکت، شاه خودی در کیش باقی می‌ماند یا خیر
   - اگر شاه در امنیت باشد -> حرکت قانونی محسوب می‌شود
        │
        ▼
۵. تصمیم‌گیری نهایی وضعیت:
   ├── تعداد حرکات قانونی = ۰ و شاه در کیش است ───────> کیش و مات (CHECKMATE) ❌
   ├── تعداد حرکات قانونی = ۰ و شاه در کیش نیست ──────> پات / مساوی (STALEMATE) ⚖️
   ├── تعداد حرکات قانونی > ۰ و شاه در کیش است ───────> کیش (CHECK) ⚠️
   └── تعداد حرکات قانونی > ۰ و شاه در کیش نیست ──────> وضعیت عادی (NORMAL) ✅
```

برای اطمینان از صحت الگوریتم در انواع سناریوها:


### سناریوهای مورد آزمون در تست‌ها:
1. **مات مبتدیان (Fool's Mate):** مات سریع سفید در ۲ حرکت توسط وزیر سیاه در h4.
2. **مات ناپلئونی (Scholar's Mate):** مات سیاه در f7 با همکاری وزیر و فیل سفید.
3. **مات خفه‌کننده با اسب (Smothered Mate):** گیر افتادن شاه در گوشه و مات توسط اسب.
4. **مات عرض آخر (Back-Rank Mate):** مات شاه پشت سد پیاده‌های خودی توسط رخ.
5. **پات کلاسیک وزیر (Corner Queen Stalemate):** گیر افتادن شاه بدون کیش و بدون حرکت.
6. **پات شاه و پیاده (Pawn Lock Stalemate):** بن‌بست کامل با پیاده و شاه در گوشه.
7. **کیش ساده با راه فرار (Check with Escape):** کیش شدن با داشتن امکان سد کردن یا فرار.
8. **وضعیت شروع استاندارد (Initial Position):** ۲۰ حرکت قانونی برای سفید بدون کیش.
9. **اعتبارسنجی نبود شاه (Missing King):** اعلام خطای نامعتبر بودن صفحه.
10. **اعتبارسنجی پیاده در ردیف آخر یا اول:** اعلام غیرمجاز بودن صفحه.
11. **اعتبارسنجی کیش بودن شاه حریف در نوبت بازیکن:** جلوگیری از سناریوی غیرممکن.

## 💻 نمونه استفاده از الگوریتم در پایتون

```python
from engine.board import Board
from engine.evaluator import evaluate_board

board = Board()

# بارگذاری وضعیت مات ناپلئونی با رشته FEN
board.load_fen("r1bqkb1r/pppp1Qpp/2n2n2/4p3/2B1P3/8/PPPP1PPP/RNB1K1NR b KQkq - 0 4")

# ارزیابی وضعیت برای نوبت سیاه ('b')
result = evaluate_board(board, active_turn='b')

print("وضعیت:", result["status"])         # CHECKMATE
print("وضعیت فارسی:", result["status_fa"]) # کیش و مات
print("در کیش است؟:", result["in_check"])  # True
print("حرکات قانونی:", result["legal_moves_count"]) # 0
print("توضیح:", result["explanation_fa"])
```
